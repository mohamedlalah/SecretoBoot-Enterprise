# SecretoBoot V9 — GitHub Release Notes

## English

SecretoBoot V9 is a Windows UEFI boot manager for supported Windows, Android-x86/Bliss OS and Linux multi-boot setups. It includes automatic discovery, a branded rEFInd 0.14.2 boot menu, one-time test boot, persistent default mode, Windows-First Compatibility for restrictive firmware, a simplified management UI, and recovery tools.

**Important:** Compatibility depends on the PC firmware and storage layout. Back up important data and keep Windows recovery media available.

## Français

SecretoBoot V9 est un gestionnaire de démarrage UEFI pour Windows, conçu pour les configurations multi-boot compatibles avec Windows, Android-x86/Bliss OS et Linux. Il intègre la détection automatique, un menu rEFInd 0.14.2 personnalisé, un démarrage de test unique, un mode par défaut permanent, un mode de compatibilité Windows-First et des outils de récupération.

**Important :** la compatibilité dépend du firmware et de la configuration des disques. Conservez une sauvegarde de vos données et un support de récupération Windows.

## العربية

SecretoBoot V9 هو مدير إقلاع UEFI لويندوز، مخصص لأجهزة Multi-Boot المتوافقة مع Windows وAndroid-x86/Bliss OS وLinux. يتضمن اكتشاف الأنظمة تلقائيًا، واجهة إقلاع مبنية على rEFInd 0.14.2، اختبار إقلاع لمرة واحدة، وضع افتراضي دائم، Windows-First Compatibility للأجهزة التي تعيد ويندوز إلى الأولوية، وواجهة إدارة مبسطة مع أدوات استرجاع.

**مهم:** التوافق يختلف حسب Firmware وبنية الأقراص. احتفظ بنسخة احتياطية من ملفاتك ووسيط استرجاع Windows قبل تغيير إعدادات الإقلاع.
